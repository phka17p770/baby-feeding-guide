# 【便民】四川省妇幼保健院推出住院病案复印线上预约，还能邮寄到家！

> 更新时间：2026-09-11 (UTC+8)

**复印住院病案不想跑腿怎么办？**

**用微信预约！**

**邮寄到家、预约自提！**

**省时、省力、更省心！**

四川省妇幼保健院积极响应“互联网+医疗”改善医疗服务精神，为患者提供更便捷、高效、精准的服务，今年1月正式推出微信公众号线上“病案复印”服务，让便民惠民举措真正落到实处。
该服务的推出为出院病人节省了大量往返医院的时间和交通费用，患者只需关注医院微信公众号即可进行病案复印线上预约，可邮寄到家和预约自提，同时支持本人和代办他人服务。病案管理科工作人员收到预约申请后进行审核，并在申请人线上付费（复印费）后进行病案打印，交由快递公司（目前仅限于邮政EMS到付）送至申请人预留收货地址或等待申请人自提。
**操作流程**

**添加关注医院公众号**

扫描四川省妇幼保健院微信公众号官方二维码或搜索“四川省妇幼保健院”公众号添加关注。

 

**实名认证**

在微信公众号中，选择“首页-病案复印-病案邮寄或复印预约”，即可进入人证核验界面。

- 
拍照上传身份证正反面。

- 
人脸拍照上传。

- 
输入手机号码，点击人证核验完成实名认证。

  

****

**病案邮寄**

1.人证核验后，进入系统点击“病案邮寄”或者“复印预约”，此时需要阅读业务协议，同意协议后点击上方复印目的按钮进行选择，不同意协议回到首页。

- 
若为患者本人申请，页面会自动显示可复印的病案信息。

- 
若为代他人办理，目前仅限于代办未成年人（未满18周岁）住院病案复印。

2.选择复印目的（以界面具体内容为准）,如需其他特殊要求，可在下方备注栏填写，确认后点击下一步。

3.输入收件信息（自提病案系统会自动省略此步），确认信息后点击确定即可提交申请。（若审核时被驳回，可以到窗口进行办理，如若仍需要邮寄病案，需要重新进行申请过程。）

4. 审核通过后，点击通知信息进行付费或取消订单操作。

 

 

5.确认信息后点击提交，即可进行支付，支付成功后等待邮寄病案即可（快递查询需快递公司最终确认后方可查询）。

 

6.【未成年人病历】选择“代他人办理-输入患者信息”，然后录入未成年人姓名、住院号，点击“确认”后会在下面显示未成年人住院信息，点击“下一步”后继续，其他流程如上。

特别说明：姓名（例如某某之子）和住院号务必与出院证上完全一致。

 

**服务相关说明**

一、根据《医疗机构病历管理规定》，复印病案需您提供有效身份证件，所有网上预约病案复印申请需要对您进行身份认证；

 

二、非患者本人进行申请的，请根据平台提示提供相关证明材料后，才可以进行申请。

 

三、出院即可预约，出院后7个工作日可对预约病案进行复印邮寄，如果无法通过微信预约须到医院窗口现场办理。

 

四、病案管理科联系电话：028-65978212。   

**病案复印常见问题**

一、患者可随时提交网上病案复印申请，医院审核通过后即可在线支付复印费用。

 

二、为保证复印病案申请顺利通过，请按照平台提示认真上传真实的、完整的、标准的相关证明材料。

 

三、线上申请病案邮寄（邮寄费到付）服务，请认真填写邮寄信息，并再三核对信息的准确性，以确保病案复印件准确无误的邮寄到您的手中。
