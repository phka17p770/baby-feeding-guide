# 试管婴儿受精方式如何选择？我应该做一代还是二代？

很多患者在进入取卵周期的时候，不知道该如何选择自己的受精方式。听说有一代和二代，那么到底是该做一代还是二代呢？就此问题，今天为大家解读一下。

**01 常规受精**

**一代就是体外受精-胚胎移植的常规受精方式（IVF），**是将取到的卵子与优化处理后的精子在培养皿中自然结合受精，形成受精卵及胚胎并移植到宫腔的过程。**主要针对于女性因素的不孕症（如输卵管阻塞等），男方精液参数正常的患者。**

****

**02 卵胞浆内单精子显微注射**

**二代就是卵母细胞胞浆内单精子显微注射（ICSI）。**

这时有很多患者问，二代是不是比一代好？需要强调的是，ICSI并不是技术上的更新换代，**ICSI主要是针对男性因素的不育症，如严重少，弱，畸形精子症，无精子症患者。**这些患者由于精子数量太少，精子活动率低，因此需要通过显微操作将精子注射到卵母细胞中，完成受精。除此之外，ICSI还适应于有前次受精失败史（精卵结合障碍），胚胎植入前遗传学检查（PGT），解冻卵子周期的患者等。

**03 ICSI指征**

**卫健委辅助生殖实施规范明确的ICSI指征为：**

①严重的少、 弱、 畸精子症; 

②不可逆的梗阻性无精子症; 

③生精功能障碍 (排除遗传缺陷疾病所致 );

④免疫性不育; 

⑤体外受精失败; 

⑥精子顶体异常; 

⑦需行植入前胚胎遗传学检查的。

**欧洲人类生殖与胚胎学协会（ESHRE）的ICSI指征包括以下内容：**

少精子症，弱精子症（特指完全不动的精子）及畸形精子症﹙正常形态精子比例＜4%﹚，睾丸或附睾来源的精子，射精障碍如逆行射精，反复常规IVF受精失败,高抗精子抗体滴度，癌症患者的自身冻存精子等。

**荷兰妇产科学会提倡精液处理后的总活动精子数<1×106个的情况首选ICSI治疗，**总活动精子数位于1-10x106之间时，以常规IVF治疗为主，总活动精子数＞10×106时，按不明原因不孕处理先进行人工授精若干周期，多次失败后再考虑IVF治疗.

**在非男性因素不孕方面并没有考虑ICSI受精方式。**

**04 二代是否优于一代**

需要注意的是，从文献数据分析上看，ICSI受精、常规受精成功率并没有区别，并非“二代试管”比“一代试管”好。首先**常规受精和ICSI受精只是不同的受精方式，ICSI并不能改善胚胎质量，胚胎的质量主要取决于卵子和精子的质量，与受精方式关系不大。**一代试管与自然怀孕比，只是受精地点从体内移到体外，受精过程是一样的。二代试管是在显微镜下将一个相对活力好的精子直接注射到卵细胞浆内，是一个有创的技术。

因此在选择的时候，千万不要认为ICSI要比常规受精好，要根据自己的情况选择合适的受精方式，要选对的，不要只选贵的。
